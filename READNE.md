# Smart HR and Employee Management System

## Project Overview
A Django-based application for managing employee information,
attendance, leave, payroll, and HR reporting.

## Backend Stack
- Python
- Django
- Django REST Framework
- PostgreSQL

## Backend Responsibilities
- Project configuration
- Database connectivity
- Environment variables
- Logging
- Database migrations
- Backend verification

## Security
Never commit the local .env file, passwords,
secret keys, or other confidential information.
